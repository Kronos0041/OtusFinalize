# ClothesShop

ClothesShop — дипломный проект iOS-приложения с демонстрационным каталогом аксессуаров. Пользователь может искать товары, просматривать карточки, сохранять понравившееся и собирать корзину. Приложение написано на SwiftUI и поддерживает iOS 17 и новее.

## Возможности

- [x] Пошаговый вход и регистрация по email с подтверждением адреса, восстановление пароля и выход из аккаунта.
- [x] Каталог с поиском, фильтром по категориям и обновлением свайпом. При прокрутке категории остаются закреплёнными сверху.
- [x] Карточка товара с описанием, ценой, выбором размера, полноэкранным фото, масштабированием и возможностью поделиться.
- [x] Избранное: добавление, удаление и очистка списка. Выбранные товары сохраняются на устройстве между запусками.
- [x] Корзина: изменение количества, удаление товаров, итоговая сумма и демонстрационное оформление.
- [x] Уведомления с отметкой о прочтении и счётчиком непрочитанных, а также профиль со сменой email и пароля.

Вход через Apple, Google и Facebook пока показан только в интерфейсе. Демонстрационное оформление очищает корзину; оплату и реальный заказ приложение не создаёт.

## Требования

- macOS и Xcode с поддержкой iOS 17;
- симулятор iPhone с iOS 17 или новее либо совместимое устройство;
- подключение к интернету и доступ к email для регистрации и просмотра каталога.

## Установка

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/Kronos0041/OtusFinalize.git
   cd OtusFinalize
   ```

2. Откройте `ClothesShop.xcodeproj` в Xcode и дождитесь загрузки зависимостей через Swift Package Manager.
3. Выберите схему `ClothesShop` и симулятор iPhone, затем запустите приложение.

Для запуска на устройстве укажите свою Apple Developer Team в Signing & Capabilities.

## Пример использования

1. Введите email. Если аккаунта ещё нет, придумайте пароль, подтвердите адрес по ссылке из письма и нажмите «Я подтвердил адрес» в приложении.
2. Откройте «Товары», выберите категорию или найдите товар через поиск.
3. В карточке товара рассмотрите фото, выберите размер при необходимости и добавьте товар в избранное или корзину.
4. Во вкладке «Корзина» измените количество товаров и попробуйте демонстрационное оформление.

## Технологии и библиотеки

- **Swift, SwiftUI, Observation** — интерфейс и состояние экранов.
- **MVVM** — организация экранов; протоколы репозиториев и сценарии использования разделяют интерфейс и работу с данными.
- **FirebaseCore, FirebaseAuth, FirebaseFirestore** — инициализация сервиса, учётные записи, каталог, уведомления и корзина.
- **UserDefaults** — локальное сохранение избранного и отметок о прочтении уведомлений.
- **URLSession и URLCache** — загрузка и кэширование фото товаров.
- **Swift Package Manager** — зависимости проекта; **SwiftGen** — типизированный доступ к строкам интерфейса.
